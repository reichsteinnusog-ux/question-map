# question-map

**问题地图**的画板引擎：把一份纯文本的「地图文件」显示成一张可以点读的问题地图。

- 地图上的每一个点都是一个问题；每个问题的讲解由浅入深：一个画面 → 例子 → 为什么 → 精确地说 → 什么时候失灵。
- 先猜再看；用自己的一句话代替原来的问题。
- 鼠标停在术语上看大白话解释；有地图视图；能导出成网页、Markdown 和 PDF 阅读版。

## 用法

页面里放一段地图文字，再加载 `qmap.js`：

```html
<textarea id="qmap" hidden>
# 地图：标题
## r｜根问题
### 一个画面
……
</textarea>
<script src="https://cdn.jsdelivr.net/gh/reichsteinnusog-ux/question-map@main/qmap.js"></script>
```

在 Gemini 里使用：上传《问题地图_Canvas说明》和学习资料，打开 Canvas，让 Gemini 按说明画初稿。

## 地图文件格式（v1）

```
# 地图：<标题>
资料：<资料名称>

## <编号>｜<问题>
父：<上一级编号>
页：<页码，可写范围>
相关：<其他编号>
### <小节标题>
<Markdown 正文；可以包含 ```svg 示意图 或 ```chart 数据图>

## 术语
- [[术语|一句大白话]]：例子
```

- 根问题编号为 `r`，其余为 `q1`、`q2`……编号永不改变。
- 讲解梯子的五个小节标题：`一个画面`、`例子`、`为什么`、`精确地说`、`什么时候失灵`；也可以加别的小节。
- `我的猜测`、`我的一句话` 是学习者自己写的小节。
- 只写了问题、没有小节的问题叫"迷雾"，等学习者走到那里再展开。
- 示意图 svg 只用这几个 class 上色：`c-ink` `c-muted` `c-accent` `c-soft` `c-line` `c-paper`。

格式是纯文本，任何 AI、任何笔记软件都能读写。
